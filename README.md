# Teleprompter privacy policy

Public privacy policy for the Teleprompter Android app by Nexdert.

Published with GitHub Pages at:
https://drankit2029-sys.github.io/teleprompter-privacy/

Contact: Noxedus2008@gmail.com

## Page

A single static `index.html` with no build step, external fonts, images,
analytics, cookies, or third-party requests. The visual language mirrors the
app's neo-brutalist theme (paper, ink, teal, magenta, gold, hard offset
shadows).

- Responsive from 320 px phones through 4K and ultrawide displays.
- Collapsible contents on phones and short landscape screens; sticky,
  scrollable contents on desktop.
- Keyboard accessible, visible focus rings, skip link, reduced-motion support.
- Print stylesheet that drops background colours and shadows, hides navigation,
  and expands external link URLs.
- Scroll progress bar, deep links per section, and a back-to-top control.
